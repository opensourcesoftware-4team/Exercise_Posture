# 운동 공유 게시판 개발 — min-yougyeong

## 1. 담당 역할

- **담당자:** 민유경
- **담당 기능:** 운동 정보 공유 게시판(커뮤니티)
- **목표:** 사용자가 운동 경험과 팁을 게시글로 공유하고, 운동 종류별로 게시글을 찾아볼 수 있는 기능 구현

## 2. 핵심 구현 기능

| 기능 | 설명 | 우선순위 |
| --- | --- | --- |
| 게시글 작성 | 닉네임, 제목, 운동 종류, 본문을 입력하여 게시글 작성 | 필수 |
| 게시글 저장 | 작성한 게시글을 데이터베이스에 저장 | 필수 |
| 게시글 목록 조회 | 저장된 게시글을 목록 형태로 표시 | 필수 |
| 게시글 상세 조회 | 선택한 게시글의 제목, 작성자, 운동 종류, 본문 등을 표시 | 필수 |
| 운동 종류별 분류 | 스쿼트, 푸시업, 플랭크 등 카테고리를 기준으로 게시글 필터링 | 필수 |
| 게시글 수정 및 삭제 | 작성된 게시글의 내용을 변경하거나 삭제 | 추가 구현 검토 |
| 운동 결과 연동 | 운동 횟수, 자세 정확도 등의 통계를 게시글에 첨부 | 향후 확장 |

> **구현 범위:** 회원가입·로그인 기능 없이, 작성 시 닉네임을 직접 입력하는 방식으로 구성한다.

## 3. 기술 스택 및 시스템 구성

| 구분 | 기술 | 역할 |
| --- | --- | --- |
| 백엔드 | Python, Flask | 게시판 API 및 요청 처리 |
| ORM | SQLAlchemy | 게시글 데이터 모델 정의 및 DB 접근 |
| 로컬 데이터베이스 | SQLite | 개발 단계 게시글 저장 |
| 프론트엔드 연동 | Streamlit (팀 협의) | 게시판 화면 구성 및 Flask API 호출 |

**예상 구조**

```text
Streamlit 화면 (팀원 담당 또는 협업)
       │ HTTP 요청
       ▼
Flask 게시판 API (담당 기능)
       │ SQLAlchemy
       ▼
SQLite (로컬 데이터베이스)
```

## 4. 데이터 모델 초안

**Post(게시글)**

| 필드 | 예시 타입 | 설명 |
| --- | --- | --- |
| id | Integer | 게시글 고유 ID, 기본 키 |
| nickname | String | 작성자 닉네임 |
| title | String | 게시글 제목 |
| exercise_type | String | 운동 종류 |
| content | Text | 게시글 본문 |
| created_at | DateTime | 작성 시각 |
| updated_at | DateTime | 수정 시각 (수정 기능 구현 시) |

## 5. API 설계 초안

| 메서드 | 경로 | 기능 |
| --- | --- | --- |
| POST | `/api/posts` | 게시글 작성 |
| GET | `/api/posts` | 게시글 목록 조회 |
| GET | `/api/posts/<post_id>` | 게시글 상세 조회 |
| GET | `/api/posts?exercise_type=squat` | 운동 종류별 필터링 |
| PUT | `/api/posts/<post_id>` | 게시글 수정 (추가 검토) |
| DELETE | `/api/posts/<post_id>` | 게시글 삭제 (추가 검토) |

※ 경로는 **제안안**이며 실제 코드 및 팀 API 규칙에 맞게 조정한다. 로그인 없이 수정·삭제를 제공할 경우 작성자 확인 방식이 별도로 필요하다.

## 7. 완료 기준

- [ ] 닉네임·제목·운동 종류·본문 입력으로 게시글을 생성할 수 있다.

- [ ] 전체 게시글 목록을 불러올 수 있다.

- [ ] 필수 입력값 누락 및 존재하지 않는 게시글 요청을 처리한다.
- [ ] 팀 프론트엔드와 API가 정상 연동된다.
