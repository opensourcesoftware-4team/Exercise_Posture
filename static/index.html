Connectivity Guide

Windows 휴대폰 연결 인프라

일반적인 노트북 내장 웹캠은 렌즈 각도가 낮아 왜곡이 발생하기 쉽고 전신 촬영 거리를 확보하기 어렵습니다.

Windows 운영체제의 '휴대폰 연결' 기능을 활용하여 스마트폰 후면 카메라를 무선 웹캠으로 동기화하십시오. 유연한 고도 확보가 가능해져 정밀한 모션 랜드마크 분석이 가능해집니다.

AI Tracker User Guide

4단계 코어 분석 프로세스

정밀 실시간 비전 엔진을 가동하기 위한 최적의 파이프라인 순서입니다. 완벽한 데이터 수집을 위해 아래 단계를 준수하십시오.

  • 1
    타겟 종목 선택: 대시보드 진입 전 분석할 운동(스쿼트, 푸시업, 플랭크)옵션을 선택합니다.
  • 2
    카메라 세로 정렬: Windows 휴대폰 연결을 가동하고 관절 랜드마크가 왜곡 없이 전신 전형이 잡히도록 배치합니다.
  • 3
    실시간 운동 수행: 인공지능이 랜드마크 위치 연산을 실시간으로 모니터링하며 정석 자세로 세션을 진행합니다.
  • 4
    운동 기록 저장: '분석 종료 및 세션 데이터 저장' 버튼을 통해 해당 운동 기록을 LocalStorage에 최종 저장합니다.

Latest Session Performance

세부 오답 누적 디스플레이

스쿼트, 푸시업, 플랭크 각 종목별로 정의된 에러 횟수를 인터페이스로 시각화합니다.
